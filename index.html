CNA Samples

Microsoft's XNA 4.0 samples, ported to C++ with CNA and compiled to WebAssembly. Every sample below runs in this browser on WebGL 2 — no plugin, no download.

Work in progress

Nearly 100 XNA samples have already been ported to CNA. We are validating their native and Release web builds and publishing them here one by one, so this gallery will keep growing.

Browse the ports and follow progress on GitHub →
