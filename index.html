CNA Samples

Microsoft's XNA 4.0 samples, ported to C++ with CNA. Playable entries run in this browser on WebGL 2; rights-limited projects are documented without a game bundle.

Work in progress

90 XNA samples were ported to CNA. Their native and web builds are validated. Web builds were published in this gallery.

Browse the ports and follow progress on GitHub →

The playable builds in this gallery use C++ ports and CNA's C++ API; these versions have so far been tested on the Web and Linux desktop. Separately, CNA.NET, the CNA C# binding, runs nearly all of the same samples from their original, unchanged C# source on the Web, desktop and Android. Other platforms have not yet been tested. See the CNA.NET sample collection ↗.
