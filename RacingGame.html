About this game

The CNA C++ port includes the complete menu and race loop, three tracks, car selection, replay ghost, highscores, XACT audio, shadows and post-processing. It uses the authentic XNA 4.0 Content Pipeline output during local qualification.

The game has also been run through CNA.NET, the CNA C# binding, using its original C# game source unchanged. That C# route has been exercised on desktop, Web and Android; other platforms have not yet been tested. Its evidence is tracked in the CNA.NET games catalogue ↗.

Publication status

The C++ version has been tested on the Web and Linux desktop. The browser product remains local because its 286 MiB payload contains original game assets whose available provenance does not include a redistribution grant. This page therefore provides a screenshot and project status only.
