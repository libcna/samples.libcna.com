About this sample

This tutorial demonstrates four ways to configure a Windows Phone game's screen orientation. This port starts in the original tutorial’s fourth configuration: full resolution, portrait and both landscape positions, with tap-to-lock behavior and a centered direction guide.

The upstream download starts in a static landscape configuration. At the owner’s request this port selects the existing fourth configuration and enables CNA’s optional keyboard orientation emulation. A position requested while locked takes effect after unlocking. The other tutorial configurations remain source edits.
